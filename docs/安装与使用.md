# 安装与使用

安装 Release 中的三个 APK，并先分别打开 QQ、高德完成其许可和初始化。同签测试版可覆盖，其他签名不保证覆盖；重要音乐与地图数据应先自行备份。允许地图悬浮窗、文件访问和可选天气定位，将追风桌面设为默认桌面。

在主题设置中选择关联自动启动、默认主页、背景、颜色、字体、透明度和控件布局。天气设置可选择自动定位或手动默认地点，初始地点为北京市；天气仍来自 Open-Meteo。

关联自动启动时，QQ启动动画结束后立即尝试返回，高德启动动画结束后延迟500ms尝试返回。QQ另外在动画结束后650ms、3000ms兜底，高德在2350ms、10000ms兜底；三个时刻分别从动画结束计算，不相互累加。成功返回或离开本次关联流程后停止重试。桌面另保留20秒单目标、45秒整体异常保护。普通手动打开应用仍使用官方启动画面并停留在应用内。

高德首次原生界面就绪后请求3D车头向上，原生成功回执后记住初始化结果；之后可自行切换视角，不在每次重启覆盖手动设置。

文件中心的文件管理浏览所有可访问目录，文件传输只显示接收目录。开启 HTTPS 后按车机地址访问，端口默认 8888、访问码默认 123456。手机可反复添加文件累计至 200 个，支持多选的选择器可一次多选，支持文件夹选择的浏览器可批量加入文件夹。每文件最大 300 MiB。

实车验收时检查：冷启动 QQ→高德→桌面、普通打开仍停在应用、快速切换卡片不空白/不残留、搜索/导航触摸与尺寸改变、倒车影像全屏让位、定位的省市县、手机实际选择器的多选及大文件接收。具体构建与验证边界见首发检查报告。
