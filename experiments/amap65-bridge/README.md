# 高德 6.5 原生卡片适配代码

当前发行版 R1 使用 `6.5.0.601323` 的原有 Surface 与系统级悬浮窗（API 19 为 TYPE_PHONE 2002），同步实际缓冲尺寸、UI 视口与触摸坐标。它不是子窗口、截图或任意应用虚拟化实现。

SHOW/CLOSE 命令按会话与序号处理，同签权限约束初次 Binder 交接。重复 SHOW 在初始化暂未完成、生命周期改变或先前尝试失败后可重试，已经显示时保持幂等。窗口依赖桌面实时焦点证明、心跳与 Binder 生存状态，关屏、失焦/切页或主机失联时撤下。

`AdapterTrust`核对准确包名、版本、revision-10标记与签名证书。`DefaultMapView`在首次原生HMI就绪后，通过现有`a20` MapOperaAction（`EXTRA_TYPE=2`、`EXTRA_OPERA=2`）请求3D车头向上；只有收到原生成功回执才持久化一次性初始化完成。用户手动切换视角后不反复强制覆盖，未确认或初始化暂不可用时有界重试。

`Amap65Runtime` 只针对这一精确版本的字段和回调，其他 APK 不能直接套用。原生渲染、搜索、导航、车机倒车影像及实际帧延迟需实车验证。首发检查报告区分 JDK 逻辑测试、既有替身窗口证据和本轮未完成的 Android 运行测试。

本目录只含项目自有桥接源码。商业源码、反编译内容、原生库及签名私钥不包含在此仓库。`tools/refresh_companions.py` 可对已含本项目钩子的配套 APK 更新自有辅助类，不宣称可从此源码重建原高德商业应用。

刷新配套APK仍需与输入包一致的签名私钥。工具会核对证书，不能用另一台机器新生成的debug.keystore替代，也不修改原有启动证书策略。
