# 配套应用双启动与返回桌面

普通入口保留官方画面，只有桌面自动关联启动携带短时标记、PendingIntent回执、Messenger备选回执、随机会话令牌与最后目标标记。地图启动图和原生渲染遮罩独立观察；遮罩变化不清除启动图完成状态，遮罩未退出不阻止动画完成后的有限返回流程。

自动关联启动在各自启动动画结束后返回桌面，保留三重有限尝试。尝试耗尽后，重复ready事件不会重新启动。成功返回、关屏、其他前台、手动进入桌面、取消会话会停止后续尝试。最后一个关联目标也能直接打开追风桌面；桌面服务另保留异常保护。

`tests/startup-return/`直接编译生产类并在JVM Android替身上检查39个场景、165项断言，包括默认视角辅助类。这不等于商业应用或Android生命周期实测。

辅助类不改变原应用初始化流程，也不把普通打开变成自动返回。`QqHome`为QQ增加返回桌面入口。商业UI资源和原生库保留在用户自己的配套APK中，仓库不含它们。
